# Dashboard de Vendas Porsche com Agentes de IA

Dashboard interativa desenvolvida a partir de uma base de dados de vendas da Porsche, como parte do desafio da **DIO**, utilizando recursos de **Inteligência Artificial, HTML, CSS e JavaScript** para transformar dados de vendas em informações visuais e úteis para análise.

## Sobre o projeto

O projeto teve como objetivo criar uma dashboard de vendas da Porsche em **HTML**, permitindo visualizar e analisar os dados de forma interativa, sem depender das limitações de uma planilha do Excel.

A construção da dashboard foi orientada por perguntas de negócio, buscando transformar os dados disponíveis em indicadores e visualizações que facilitem a identificação de padrões de vendas.

## Perguntas de negócio

A dashboard foi desenvolvida para responder às seguintes perguntas:

1. **Quais são os principais modelos de Porsche vendidos em cada cidade?**

2. **Qual ano de modelo de carro apresentou maior volume de vendas no período analisado?**

3. **Quais são os carros mais populares em cada cidade, considerando o volume de vendas?**

Essas perguntas orientaram a escolha dos gráficos, indicadores e filtros utilizados no projeto.

## Funcionalidades

A dashboard conta com:

* Filtro por modelo da Porsche
* Filtro por cidade
* Filtro por ano do modelo
* Filtro por método de pagamento
* Indicadores de total de vendas
* Indicadores de receita
* Gráficos para análise dos modelos vendidos
* Visualização dos modelos mais populares por cidade
* Análise do ano de modelo com maior volume de vendas
* Interface responsiva e interativa

## Tecnologias utilizadas

* **HTML5** para estrutura da dashboard
* **CSS3** para estilização e layout
* **JavaScript** para interatividade, filtros e processamento dos dados
* **IA generativa** como apoio na criação e desenvolvimento da solução
* **GitHub Pages** para publicação da dashboard

## Base de dados

Foi utilizada a base de dados de vendas da Porsche disponibilizada pela DIO para o desafio.

A base contém **100 registros de vendas**, com informações relacionadas aos veículos, cidades, anos dos modelos e métodos de pagamento.
